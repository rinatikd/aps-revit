# АПС для Revit 2021 (pyRevit)

Автоматизация проектирования адресной пожарной сигнализации (Болид / Рубеж). Подробности в [prd.md](prd.md).

## Состав

```
APS.extension\
├─ lib\
│  ├─ aps_rules.json   нормы, производители, кабели, питание, мастер (ДЕМО-значения)
│  ├─ apsgeom.py       чистый Python: геометрия, расстановка, шлейфы, документация, электрика
│  └─ apslib.py        Revit API: связи, помещения, потолки, смежники, размещение
└─ APS.tab\APS.panel\  кнопки 0–7
APS_Revit.html         документация, предпросмотр, расчёты, JS-порт apsgeom, сборка zip
prd.md                 требования, алгоритмы, бэклог
```

## Установка (один раз на ПК)

1. Установить [pyRevit](https://github.com/pyrevitlabs/pyRevit/releases).
2. Скопировать папку `APS.extension` в любое место, например `C:\pyRevit-ext\`.
3. pyRevit → Settings → Custom Extension Directories → добавить `C:\pyRevit-ext` → Save & Reload.
4. В Revit появится вкладка **APS**.

## Порядок работы

0 Мастер → 1 Разведка (проверить `aps_recon.json` в `APS_Revit.html` → «Предпросмотр») → 2 Извещатели → 3 ИПР и оповещение → 4 Шлейфы → 6 Схема, СО, журнал, DXF → 7 Листы → 5 Экспорт DWG.

## Важно

- Нормы и паспортные данные в `aps_rules.json` — **демо** (СП 5.13130.2009). Перед реальным проектом заполнить по СП РК 2.02-102 и паспортам (бэклог B2, B3).
- Вызовы Revit API ещё не проверены в живом Revit 2021 (бэклог B1).
- Алгоритм меняется в двух местах: `apsgeom.py` и JS-порт в `APS_Revit.html`.
